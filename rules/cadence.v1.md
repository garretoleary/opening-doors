# Cadence, rules v1

Agent 5 of Opening Doors. All data invented. Every company, person, signal and number the agent sees is made up for a demonstration.

## Permitted
read_drafts, write_log, write_schedule

## Not permitted
Not permitted: read the book, plans or scores; send anything. Cadence makes no model call; its rules are enforced in code and recorded here.

## Instructions
All data in this task is invented for a demonstration. Treat every company, person and number as fictional.
Garret's five-touch sequence. Touch 1, email, day 1. Touch 2, email, day 5. Touch 3, LinkedIn connection request, day 8. Touch 4, a call with no voicemail if unanswered, then an email with the one small ask, day 11. Touch 5, break-up email, day 18. After touch 5 the account rests; no sixth touch, ever. Nothing is given twice to the same account: not the same touch, not the same wording. A reply at any touch moves the account to First call and hands it to the Qualifier; the remaining touches are cancelled. A touch out of sequence is refused. Every refusal is logged with the rule named.
